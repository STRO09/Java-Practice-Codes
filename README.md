# Java Mastery Repository

A comprehensive Java learning repository covering **Hibernate with JPA annotations**, **entity relationships**, **CRUD operations**, **serialization**, **Java 8 features**, **multithreading**, and **basic Java patterns**.

---

## 📌 Topics Covered

### **Hibernate + JPA Annotations**
- **Entity Mapping** with `@Entity`, `@Table`, `@Id`, `@GeneratedValue`
- **Relationships**
  - **One-to-One**
  - **One-to-Many / Many-to-One**
  - **Many-to-Many**
- **CRUD Operations** using Hibernate's Session API
- **Cascade Types** and **Fetch Types**
- **HQL (Hibernate Query Language)** basics

### **Serialization**
- Implementing `Serializable`
- **SerialVersionUID** usage
- **Transient** keyword
- Java Object Serialization and Deserialization

### **Java 8 Features**
- **Lambdas** syntax and use cases
- **Method References** (`::` operator)
- **Streams API**
  - Filtering, mapping, reducing
  - Collectors and grouping

### **Multithreading & Concurrency**
- **Thread** and **Runnable** basics
- `synchronized` keyword
- **Semaphore**
- **ReentrantLock**
- **CountDownLatch**
- **CyclicBarrier**
- **ExecutorService**
- **Callable** & **Future**

### **Basic Java Patterns (Star Patterns)**
- **Pyramid**
- **Inverted Pyramid**
- **Sandglass**
- **Hollow Diamond**
- **Right-angle Triangle**
- Other variations
